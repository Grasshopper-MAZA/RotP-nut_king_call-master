# Nut King Call Addon

A Minecraft mod addon for **Ripples of the Past** that adds the **Nut King Call** Stand from *JoJo's Bizarre Adventure Part 8: JoJolion*.

## About Nut King Call

Nut King Call is the Stand of Jobin Higashikata from JoJo's Bizarre Adventure Part 8: JoJolion.
